# 后训练学习

我将尝试按照算法工程师的思路，来设计并实现一个有害评论分类器。

项目思考的顺序如下：
1. 定义问题：定义模型要解决什么问题，以及边界在哪里
2. 定义输入输出和语义：定义输入输出的格式、字段、标签含义、以及异常输入的处理
3. 设计评估体系：定义好指标和测试集，成功的标准和错误代价
4. 数据策略和数据准备：定义好数据集，多个数据源做统一的处理，包括数据清洗、数据增强、数据划分等
5. 建立基线：设立一个Baseline，可量化、可比较我的训练成果
6. 模型架构和训练方案：模型架构、损失函数、采样策略、训练超参数和计算资源
7. 消融实验：数据泄露检查、OOD测试、误差分析、以及检查模型是真的学会了，还是拟合了奇奇怪怪的规律
8. 概率校准和决策策略：定义模型的判断结果，包括阈值、引入人审的策略等
9. 系统性能与部署：推理性能、模型版本管理、线上监控
