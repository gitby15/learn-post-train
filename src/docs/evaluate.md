# 评估体系

## F1计算公式
```
查准率（没有误伤）
Precision = TP / (TP + FP) # 真 正例数量 / 所有预测为正例的数量
召回率（没有漏放）
Recall = TP / (TP + FN) # 真 正例数量 / 所有真正的正例数量
F1 = 2 * Precision * Recall / (Precision + Recall)
```

TP：正确识别出的威胁。
FP：正常文本被误判为威胁。
FN：真正的威胁被漏掉。
TN：正常文本被正确放行。

阈值设定：
```python
y = 1 if p > threshold else 0
```

对于F1来说，F1的结果，跟阈值没有正相关性（调大或者调小阈值，都有可能导致F1变小）

具体的阈值设定，会在后面考虑


## 泛化能力评估
L1: 基础能力泛化
评估方式：state使用训练时没见过的，但是question使用训练时出现过的

L2: 问题表达泛化
评估方式：state使用训练时见过的，但是question使用训练时没出现过的
与此同时，针对question，需要考虑针对question的语义一致性检查

L3：未见任务泛化
评估方式：任务领域相同，但是测试时出现新的有害类型

L1、L2和L3的核心区别：文本是否见过、问题是否见过、标签是否见过

### 问题改写鲁棒性
对于同一个任务，仅仅改变问题的表达方式，模型的判断是否稳定？
针对多个相同语义的不同问题，怎么评估稳定性：
- 预测翻转率：Prediction flip rate
- 概率极差：Probability Range(最大值和最小值的差)


观测指标
Precision、Recall、F1、Average Precision、翻转率、极差

### 概率质量
假设阈值是0.5，一组评测的概率，是0.51,0.49,0.51，他们的结论都是正确的，F1也是100%，但是这个结果，肯定没有0.98,0.02,0.96这一组的效果好。所以，我们需要有一个指标，来衡量决策质量
我们有两种表示决策质量的指标：
- Brier Score: 1/N * ∑(p - yi)^2 | 概率与答案的均方误差
- Log Loss: - 1/N * ∑(yi * log(pi) + (1-yi) * log(1-pi))

# 评估协议
什么是评估协议：评估协议是训练前建立的一套实验规则，确保不同的模型，是在相同的条件下接受测试，并且测试结果可以反应模型真实的泛化能力

## 评估矩阵
|测试集	| 核心问题	| 主要指标 |
|---|---|---|
|L1：新文本 | 模型能否识别未见过的文本？ | AP、F1、Precision、Recall |
|L2：新问法 | 换一种等价提问方式，模型是否仍然有效？ | AP、F1、Flip Rate、Mean Probability Range |
|L3：新任务 | 模型能否回答训练中未监督过的任务？ | AP、F1、Precision、Recall |
|概率质量   |	模型给出的概率是否合理？ | Brier Score、Log Loss |

所有指标按任务分别计算，不能只报告一个混合总分
